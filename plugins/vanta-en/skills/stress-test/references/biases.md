# Checklist of biases and traps

For each item, ask whether it is present in the plan or the reasoning. Report only the ones you actually find.

## Estimation biases

- **Planning fallacy.** Time and cost estimated on the ideal case. Check: how did similar projects go (reference class), not this one?
- **Anchoring.** A first number (price, deadline, budget) conditions all the others. Check: where does that number come from?
- **Survivorship.** Only the successful cases are considered. Check: how many tried the same thing and disappeared?
- **Overconfidence.** Estimate ranges that are too narrow. Check: could the real value reasonably be double or half?

## Judgement biases

- **Confirmation.** Only supporting evidence is sought. Check: which data would change your mind, and has anyone looked for it?
- **Sunk costs.** Continuing because you have already invested. Check: starting from zero today, would you make the same choice?
- **Status quo.** The current option is preferred only because it is the current one.
- **Availability.** A recent or vivid example weighs more than the data.

## Strategic biases

- **Passive adversary.** The plan assumes competitors, customers or counterparts will not react.
- **Hidden dependency.** The plan holds only if a person, supplier or platform keeps behaving as it does today.
- **First order only.** The immediate effect is evaluated, not the reaction it provokes.
- **Ignored irreversibility.** A choice that is hard to undo is treated as a trial.

## Language traps

- **Vague terms.** "Success", "growth", "quality" without a measure.
- **False dichotomy.** Two options presented as the only ones.
- **Hidden premise.** The question takes for granted something unverified.
- **Misleading average.** An average that hides a very uneven distribution.
